# 📌 Visão Geral

Sistema de monitoramento automático da altura da grama em rodovias da Motiva.

Cobertura:

- mais de 5.000 km

Objetivo:

- identificar necessidade de roçagem antes de virar problema

---

## Como funciona

O sistema combina três fontes:

- satélite (Sentinel-2)
- veículo patrulha
- sensores IoT

Todos os dados entram no mesmo pipeline e geram um score por segmento.

---

## Resultado

Quando necessário:

- alerta é gerado
- ordem de serviço é criada
- execução é organizada automaticamente
