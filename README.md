# Challenge FIAP - Motiva

Monorepo com backend e web/webview do challenge da motiva

## Como rodar

1. Instalar NodeJS (v20 LTS)
2. Rodar `npm install` na raiz do projeto
3. Rodar `npm run dev` na raiz do projeto

## Apps

- `apps/backend` — API REST (NestJS)
- `apps/web` — Dashboard web + PWA (Vite + React)
